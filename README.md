### 🏠 The Homelab Stack
I treat my home infrastructure like a production environment. Here's what's currently running on my **TrueNAS** & **Docker** nodes:

- **🔐 Identity & Security:** SSO via **Authentik**, Network-wide blocking with **Pi-hole**, and secure tunneling via **Cloudflare**.
- **☁️ Cloud & Productivity:** **Nextcloud AIO** for data, **Immich** for photo management, and **Paperless-ngx** for a digital office.
- **📊 Monitoring:** Full observability with **Grafana**, **Loki**, and **Uptime Kuma**.
- **🎬 Media Automation:** Fully automated pipeline for content management and distribution.
- **🌐 Reverse Proxy:** **Nginx Proxy Manager** handling SSL and traffic routing.
